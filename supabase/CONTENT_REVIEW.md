## ⚠️ 반드시 읽을 것

**이 파일(0004_seed.sql)에 들어있는 모든 의학 정보(summary, sections의 원인·집에서 돌보기·주의점, emergency의 응급신호·행동요령)는 Claude Code가 작성한 초안(draft)이며, 실제 배포 전 반드시 사람(소아청소년과 전문의 등 의료 전문가 또는 최소 신뢰 가능한 공식 자료 대조 검수자)이 내용을 검증해야 합니다.**

- 이 시드 데이터는 일반적으로 알려진 육아/소아과 상식 수준으로 작성되었으며, 의학적 사실 확인(fact-check)을 거치지 않았습니다.
- 특정 수치(체온 기준, 개월 수 등)는 참고 예시이며 최신 소아과 가이드라인과 다를 수 있습니다. **반드시 재확인 후 배포**하세요.
- 검수 전에는 스테이징/개발 환경에서만 사용하고, 프로덕션에 배포하지 마세요.

## 검수 시 확인할 §13.3 준수 기준 (전 증상 공통)

각 증상마다 아래 5개 항목을 모두 확인하세요.

- [ ] **진단 단정 금지**: "~입니다/~병입니다" 식으로 특정 질환을 단정하는 문장이 없는가? ("~일 수 있어요", "~로 알려져 있어요" 등 완곡 표현인가)
- [ ] **치료 권유 금지**: 특정 약물명(성분명/제품명) 또는 특정 제품을 "치료"·"완치"로 권하는 표현이 없는가? (해열제 등은 "의료진과 상의" 수준으로만 언급되어야 함)
- [ ] **응급신호 분리**: 응급 상황에 해당하는 내용이 `emergency` 필드로 명확히 분리되어 있고, 병원/응급실 방문을 안내하는가?
- [ ] **면책 전제**: summary/문구 전반이 "참고용" 톤을 유지하는가? (화면 UI에는 별도의 고정 의학 면책 문구가 함께 노출되어야 함 — §7.1 스키마상 symptom_infos에는 disclaimer 컬럼이 없으므로 Flutter 쪽 SymptomDetail 화면에서 전역 고정 문구로 렌더링할 것)
- [ ] **최신성/정확성**: 원인·돌봄 방법·응급 기준 수치가 현재 통용되는 소아과 가이드라인과 일치하는가?

## 검수 완료 후 절차

1. 위 표의 "상태" 컬럼을 ☐ 미검수 → ☑ 검수완료로 갱신하고 검수자·검수일을 기입한다.
2. 수정이 필요한 문구는 `supabase/migrations/0004_seed.sql`의 해당 `sections`/`emergency` JSON을 직접 수정하거나, 검수 결과를 반영한 새 마이그레이션(예: `0005_content_review_fix.sql`)으로 분리해 적용한다.
3. 16종 전체가 ☑ 검수완료 상태가 되기 전에는 프로덕션 Supabase 프로젝트에 해당 데이터를 배포하지 않는다.
4. 이후 콘텐츠를 추가/수정할 때도 본 체크리스트 형식(§13.3 5개 공통 기준 + 표)을 그대로 재사용한다.
