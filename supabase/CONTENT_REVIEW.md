## ⚠️ 반드시 읽을 것

**이 시드에 들어있는 모든 의학 정보(summary, sections의 각 타입 섹션, emergency의 응급신호·행동요령)는 Claude Code가 작성한 초안(draft)이며, 실제 배포 전 반드시 사람(소아청소년과·산부인과 전문의 등 의료 전문가 또는 최소 신뢰 가능한 공식 자료 대조 검수자)이 내용을 검증해야 합니다.**

- v1.3 콘텐츠는 공신력 출처 대조를 거쳐 작성되었고 각 카드에 `sources`(참고 자료)가 수록되어 있으나, **의료 전문가의 사람 검수를 대체하지 않습니다**.
- 특정 수치(체온 기준, 개월 수, 보관 시간 등)는 작성 시점 가이드라인 기준이며 최신 개정과 다를 수 있습니다. **반드시 재확인 후 배포**하세요.
- 검수 전에는 스테이징/개발 환경에서만 사용하고, 프로덕션에 배포하지 마세요.
- 검수 참고: 리서치 단계의 수치별 근거 메모(research_notes)는 시드에 포함되지 않으며, 세션 산출물(`scratchpad/content_final.json`)에 보존되어 있습니다.

## 검수 시 확인할 §13.3 준수 기준 (전 카드 공통)

각 카드마다 아래 6개 항목을 모두 확인하세요.

- [ ] **진단 단정 금지**: 특정 질환을 단정하는 문장이 없는가? ("~일 수 있어요", "~로 알려져 있어요" 등 완곡 표현인가)
- [ ] **치료 권유 금지**: 특정 약물명(상품명) 또는 특정 제품을 "치료"·"완치"로 권하는 표현이 없는가? (성분명 언급은 "의사·약사와 상의" 프레임인가)
- [ ] **응급신호 분리**: 응급 상황이 `emergency` 필드로 분리되어 있고 병원/응급실(엄마 카드는 산부인과/응급실/위기상담전화)을 안내하는가?
- [ ] **면책 전제**: 전반이 "참고용" 톤인가? (화면에는 audience별 고정 면책 문구가 별도 노출됨 — §11.9-5)
- [ ] **최신성/정확성**: 수치·기준이 현재 가이드라인과 일치하는가? (`sources` 목록과 대조)
- [ ] **출처 실존**: `sources`의 문서가 실존하며 본문 주장을 실제로 뒷받침하는가?

## 검수 완료 후 절차

1. 위 표의 "상태" 컬럼을 ☐ 미검수 → ☑ 검수완료로 갱신하고 검수자·검수일을 기입한다.
2. 수정이 필요한 문구는 `0009_care_seed.sql`의 해당 JSON을 직접 수정하거나 새 마이그레이션(예: `0010_content_review_fix.sql`)으로 분리해 적용하고, **앱 픽스처(`lib/data/fixtures/fixture_symptoms.dart` 계열)도 동일 값으로 갱신**한다(시드↔픽스처 동일성 계약).
3. 32종 전체가 ☑ 검수완료 상태가 되기 전에는 프로덕션 Supabase 프로젝트에 해당 데이터를 배포하지 않는다.
4. 이후 콘텐츠를 추가/수정할 때도 본 체크리스트 형식(§13.3 6개 공통 기준 + 표)을 그대로 재사용한다.
